# 📱 LeftLovers Merchant App (React Native - Expo)

> A mobile app for LeftLovers merchants to manage products, orders, promotions, analytics and settings.

Built with **Expo**, **React Native**, and **Tailwind CSS (via NativeWind)** for fast UI development.

---

## 🧠 Overview

This app is the **merchant mobile frontend** for the LeftLovers platform.  
Merchants can:

- ⚙️ Manage menus & pricing
- 🛒 View and update order statuses
- 💸 Apply promotions & deals
- 📊 Track shop performance
- 👤 Manage staff access

The app runs **locally during development** and connects to your backend deployed on **Railway**.

---

## 🧰 Tech Stack

| Layer | Technology |
|-------|------------|
| Mobile App | Expo (React Native) |
| Styling | Tailwind CSS via NativeWind |
| Navigation | Expo Router / React Navigation |
| API | Fetch to Railway backend |
| State | React Context |
| Language | TypeScript |
